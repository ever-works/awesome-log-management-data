# Red Hat

## Overview
Red Hat provides enterprise observability solutions through OpenShift and the OpenTelemetry Operator, with native OpenTelemetry support via OTLP. It targets hybrid cloud and Kubernetes environments with enterprise-grade support.

## Features
- Native OpenTelemetry support via OTLP
- OpenTelemetry Operator for Kubernetes
- Hybrid cloud observability
- Enterprise support and lifecycle management
- Integration with OpenShift

## Pricing
Paid commercial product with enterprise subscriptions.

## Deployment
Self-hosted (OpenShift/Kubernetes) or cloud-managed.
