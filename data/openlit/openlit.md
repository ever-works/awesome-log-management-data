# OpenLIT

## Overview
OpenLIT is an open-source observability solution designed for LLM and AI applications. It natively supports OpenTelemetry via OTLP for tracing and monitoring generative AI workloads.

## Features
- Native OpenTelemetry support via OTLP
- LLM and AI application tracing
- Monitoring for generative AI workloads
- Token usage and cost tracking
- Self-hosted deployment

## Pricing
Free and open-source.

## Deployment
Self-hosted.
