# VictoriaMetrics

## Overview
VictoriaMetrics is a fast, cost-effective time-series database and monitoring solution that supports OpenTelemetry via OTLP. It handles metrics, logs, and traces with high ingestion efficiency and low resource requirements.

## Features
- OpenTelemetry data ingestion via OTLP
- Time-series database for metrics
- Logs and traces support
- High ingestion efficiency
- Low RAM and storage usage
- PromQL compatible

## Pricing
Open source under Apache License 2.0; commercial editions and support available.

## Deployment
Self-hosted or cloud-managed.
