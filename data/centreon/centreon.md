# Centreon

## Overview
Centreon is a monitoring platform that combines open-source and commercial offerings. It natively supports OpenTelemetry via OTLP for infrastructure and application monitoring, including log collection and analysis.

## Features
- Native OpenTelemetry support via OTLP
- Infrastructure and application monitoring
- Log collection and analysis
- Performance metrics collection
- Alerting and notification
- Hybrid open-source and commercial model

## Pricing
Mixed open-source and commercial; commercial editions available with support.

## Deployment
Self-hosted or cloud.
