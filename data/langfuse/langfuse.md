# Langfuse

## Overview
Langfuse is an open-source LLM engineering platform that natively supports OpenTelemetry via OTLP. It provides tracing, observability, and evaluation for large language model applications.

## Features
- Native OpenTelemetry support via OTLP
- LLM tracing and observability
- Evaluation and testing
- Prompt management
- Usage and cost tracking
- Open-source core with commercial cloud

## Pricing
Mixed open-source and commercial; self-hosted open-source version available.

## Deployment
Self-hosted or cloud (Langfuse Cloud).
