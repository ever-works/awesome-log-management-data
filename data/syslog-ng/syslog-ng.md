## Overview

syslog-ng is an enhanced log daemon that supports a wide range of input and output methods: syslog, unstructured text, queueing, SQL and NoSQL. It is used for collecting, parsing, and forwarding log messages.

## Features

- Wide range of input and output methods (syslog, unstructured text, queueing, SQL, NoSQL)
- Log collection, parsing, and forwarding
- Reliable log transport with buffering
