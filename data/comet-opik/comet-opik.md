# Comet Opik

## Overview
Comet Opik is an open-source LLM observability platform for tracing, evaluating, and monitoring AI applications. It natively supports OpenTelemetry via OTLP.

## Features
- Native OpenTelemetry support via OTLP
- LLM application tracing
- Evaluation and experimentation
- Monitoring for AI workloads
- Open-source core with commercial offerings

## Pricing
Mixed open-source and commercial.

## Deployment
Self-hosted or cloud.
