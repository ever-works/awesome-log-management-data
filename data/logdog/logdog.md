## Overview

LogDog is a remote debugging/logging SDK for iOS and Android with a web UI. It captures all logs, requests and events in real-time and allows to intercept them.

## Pricing

Free for up to 100MB of logs every month.

## Features

- Remote debugging/logging SDK for iOS and Android
- Web UI for viewing logs
- Captures all logs, requests and events in real-time
- Allows interception of logs
- Free tier: up to 100MB of logs per month
