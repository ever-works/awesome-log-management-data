# Icinga 2

## Overview
Icinga 2 is an open-source monitoring and alerting platform that natively supports OpenTelemetry via OTLP. It monitors infrastructure, networks, and applications with a flexible notification system.

## Features
- Native OpenTelemetry support via OTLP
- Infrastructure and network monitoring
- Service and host checks
- Notification and escalation
- Distributed monitoring
- Web interface and API

## Pricing
Open source under GPLv2; commercial support and add-ons available.

## Deployment
Self-hosted.
