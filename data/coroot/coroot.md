# Coroot

## Overview
Coroot is an observability platform that natively supports OpenTelemetry via OTLP. It provides APM, distributed tracing, and infrastructure monitoring capabilities with an open-source core and commercial offerings.

## Features
- Native OpenTelemetry support via OTLP
- Application performance monitoring
- Distributed tracing
- Infrastructure monitoring
- Open-source core with commercial editions

## Pricing
Mixed open-source and commercial.

## Deployment
Self-hosted or cloud.
