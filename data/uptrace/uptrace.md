# Uptrace

## Overview
Uptrace is an open-source distributed tracing and APM platform that natively supports OpenTelemetry via OTLP. It provides traces, metrics, and logs with ClickHouse-based storage for high-performance observability.

## Features
- Native OpenTelemetry support via OTLP
- Distributed tracing
- Application performance monitoring
- Log management
- ClickHouse storage backend
- Open-source under MIT License

## Pricing
Free and open-source under MIT License; commercial cloud available.

## Deployment
Self-hosted or cloud.
