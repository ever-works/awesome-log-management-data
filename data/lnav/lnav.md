## Overview

lnav (the Log File Navigator) is an advanced log file viewer for the command line. It merges log content from multiple files into one view, enabling interactive navigation and real-time analysis of log files.

## Features

- Merges log content from multiple files into a single view
- Interactive navigation of log files
- Supports log file rotation and compressed files
- Real-time monitoring of log files
- Written in C++

## Pricing

Free and open source. Source code available at https://github.com/tstack/lnav
