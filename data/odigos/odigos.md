# Odigos

## Overview
Odigos is a cloud-native observability platform that natively supports OpenTelemetry via OTLP. It provides automated instrumentation and distributed tracing for Kubernetes-based applications without code changes.

## Features
- Native OpenTelemetry support via OTLP
- Automated instrumentation
- Distributed tracing for Kubernetes
- No-code application monitoring
- Service dependency mapping
- Open-source core with commercial offerings

## Pricing
Mixed open-source and commercial.

## Deployment
Self-hosted (Kubernetes) or cloud.
