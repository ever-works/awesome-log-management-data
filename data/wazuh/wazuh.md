## Overview

Wazuh is a free and open source security information and event management (SIEM) platform used for threat hunting, detection, and response. It combines log collection and analysis with file integrity monitoring and vulnerability detection.

## Features

- Log collection and analysis
- File integrity monitoring
- Vulnerability detection
- Threat hunting, detection, and response
- SIEM capabilities

## Pricing

Free and open source under the GPLv2 license.

## Deployment

Self-hosted.
