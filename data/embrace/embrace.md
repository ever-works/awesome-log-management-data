# Embrace

## Overview
Embrace is a commercial observability platform focused on mobile applications. It natively supports OpenTelemetry via OTLP for crash reporting, performance monitoring, and user experience tracking.

## Features
- Native OpenTelemetry support via OTLP
- Mobile app performance monitoring
- Crash reporting and error tracking
- User session replay
- ANR and freeze detection
- Network monitoring

## Pricing
Paid commercial SaaS; pricing varies by usage and features.

## Deployment
Cloud-based SaaS.
