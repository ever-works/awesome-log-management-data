# GreptimeDB

## Overview
GreptimeDB is a distributed time-series database that natively supports OpenTelemetry via OTLP. It is built for cloud-native environments and handles metrics, events, and log data with high efficiency.

## Features
- Native OpenTelemetry support via OTLP
- Distributed time-series storage
- Metrics, events, and log storage
- Cloud-native architecture
- SQL and PromQL query support
- Horizontal scalability

## Pricing
Mixed open-source and commercial.

## Deployment
