# ClickHouse

## Overview
ClickHouse is an open-source column-oriented database management system for real-time analytics. It supports ingestion of OpenTelemetry data via OTLP and is commonly used for storing and querying log and event data at scale.

## Features
- OpenTelemetry data ingestion via OTLP
- Columnar storage for high compression
- Real-time OLAP queries
- High ingestion throughput
- SQL interface
- Distributed processing

## Pricing
Free and open-source under the Apache License 2.0. Commercial managed service also available.

## Deployment
Self-hosted or cloud-managed.
