# Parseable

## Overview
Parseable is a log observability engine that natively supports OpenTelemetry via OTLP. It provides log ingestion, storage, and querying with Apache Parquet-compatible storage and native S3 support.

## Features
- Native OpenTelemetry support via OTLP
- Log ingestion and storage
- Log search and analytics
- Apache Parquet-compatible storage
- Native S3 object storage support
- Lightweight and efficient

## Pricing
Mixed open-source and commercial; open-source core available free.

## Deployment
Self-hosted or cloud.
