# MetricsHub

## Overview
MetricsHub is a commercial monitoring platform that natively supports OpenTelemetry via OTLP. It provides infrastructure, application, and log monitoring capabilities for hybrid and multi-cloud environments.

## Features
- Native OpenTelemetry support via OTLP
- Infrastructure monitoring
- Application performance monitoring
- Log monitoring and analysis
- Hybrid cloud support
- Alerting and reporting

## Pricing
Paid commercial product; enterprise licensing.

## Deployment
Self-hosted or cloud.
