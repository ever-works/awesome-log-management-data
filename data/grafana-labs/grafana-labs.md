# Grafana Labs

## Overview
Grafana Labs provides an observability stack including Grafana (visualization), Loki (logs), Tempo (traces), Mimir (metrics), and Pyroscope (profiling). It natively supports OpenTelemetry via OTLP across all signals. Grafana Labs offers both open-source and commercial offerings.

## Features
- Native OpenTelemetry support via OTLP
- Grafana dashboards and visualization
- Loki for log aggregation
- Tempo for distributed tracing
- Mimir for metrics
- Pyroscope for continuous profiling
- Multi-tenant and scalable architecture

## Pricing
Mixed open-source and commercial; free self-hosted and Grafana Cloud tiers available.

## Deployment
Self-hosted or cloud (Grafana Cloud).
