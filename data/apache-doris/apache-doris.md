# Apache Doris

## Overview
Apache Doris is an open-source analytical database that natively consumes OpenTelemetry data via OTLP. It is designed for high-performance, real-time analytics on large datasets.

## Features
- Native OpenTelemetry support via OTLP
- Vectorized execution engine
- Real-time OLAP analytics
- Supports log and metrics ingestion
- High concurrency and low latency queries

## Pricing
Free and open-source under the Apache License 2.0.

## Deployment
Self-hosted.
