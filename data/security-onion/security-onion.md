## Overview

Security Onion is a Linux distribution for threat hunting, enterprise security monitoring, and log management. It bundles a suite of open-source security tools for network security monitoring (NSM) and log analysis.

## Features

- Threat hunting and enterprise security monitoring
- Centralized log collection and analysis
- Network security monitoring
- Bundled open-source security toolset

## Pricing

Free and open source under the GPLv2 license.

## Deployment

Self-hosted (Linux distribution / virtual appliance).
