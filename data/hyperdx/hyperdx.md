# HyperDX

## Overview
HyperDX is an open-source observability platform that natively supports OpenTelemetry via OTLP. It unifies logs, metrics, traces, and session replay in a single interface for debugging distributed systems.

## Features
- Native OpenTelemetry support via OTLP
- Unified logs, metrics, traces, and session replay
- Log search and analytics
- Distributed tracing
- Session replay
- Self-hosted and cloud options

## Pricing
Mixed open-source and commercial; open-source core available free.

## Deployment
Self-hosted or cloud.
