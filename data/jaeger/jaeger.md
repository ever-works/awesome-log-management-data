# Jaeger

## Overview
Jaeger is an open-source, end-to-end distributed tracing platform. It natively consumes OpenTelemetry data via OTLP and is used for monitoring and troubleshooting complex microservices architectures. Jaeger is a graduated project of the Cloud Native Computing Foundation (CNCF).

## Features
- Native OpenTelemetry support via OTLP
- Distributed context propagation
- Distributed transaction monitoring
- Root cause analysis
- Service dependency analysis
- Performance and latency optimization
- Multiple storage backends (Elasticsearch, Cassandra, etc.)
