# qryn

## Overview
qryn is an observability platform that natively supports OpenTelemetry via OTLP. It is compatible with Loki, Prometheus, and OTLP formats for logs, metrics, and traces, offering a unified observability stack.

## Features
- Native OpenTelemetry support via OTLP
- Log management and analytics
- Metrics and traces support
- Loki and Prometheus compatible
- Unified query interface
- Open-source core with commercial offerings

## Pricing
Mixed open-source and commercial.

## Deployment
Self-hosted or cloud.
