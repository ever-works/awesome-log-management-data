## Overview

Logspout is a log router for Docker containers. It attaches to all containers on a Docker host, captures their stdout and stderr output, and forwards the logs to a configured destination.

## Features

- Captures container logs (stdout/stderr) from Docker
- Forwards logs to configurable destinations
- Supports custom modules for additional output targets
- Lightweight Docker log routing

## Deployment

Self-hosted as a Docker container
