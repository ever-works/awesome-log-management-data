# DataBuff

## Overview
DataBuff is an open-source observability platform with native OpenTelemetry support via OTLP. It offers centralized log management, metrics collection, and distributed tracing.

## Features
- Native OpenTelemetry support via OTLP
- Centralized log management
- Metrics collection and visualization
- Distributed tracing
- Self-hosted deployment

## Pricing
Free and open-source.

## Deployment
Self-hosted.
