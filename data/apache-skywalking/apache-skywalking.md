# Apache SkyWalking

## Overview
Apache SkyWalking is an open-source application performance monitoring (APM) and observability platform for distributed systems. It natively consumes OpenTelemetry data via OTLP for tracing, metrics, and logs.

## Features
- Native OpenTelemetry support via OTLP
- Distributed tracing
- Service mesh observability
- Log analysis and aggregation
- Application performance monitoring
- Multi-language agent support

## Pricing
Free and open-source under the Apache License 2.0.

## Deployment
Self-hosted.
